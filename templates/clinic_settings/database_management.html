How to Export

  1. Click "Download Database Backup" to save a copy of your database
  2. Store the .sqlite3 file in a safe location (USB drive, cloud, etc.)
  3. Export regularly to keep your backups up to date

How to Import

  1. Export first! Always download your current database before importing
  2. Drag and drop or browse for the .sqlite3 file you want to restore
  3. Click "Import Database" and confirm the action
  4. Restart the server after import for changes to take effect
